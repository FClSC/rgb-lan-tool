# 局域网 RGB 灯控制器（实验一 / 第二课）

用一个自己写的小工具替代厂商那个"实验室/课程"入口，只做**局域网模式**：
手机连上模块热点 → TCP 直连模块 → 模块把字节原样转给 Arduino → RGB 灯变色。

不依赖厂商服务器、不依赖公众号、不需要外网。

提供两种形态：

- **安卓 App**（`app/`）：手机装一个，单机使用，最方便；
- **网页版**（`web/`）：电脑跑一个桥接程序，手机浏览器直接打开，**不用装任何东西**，还能一台电脑带全班。见文末 [第九节](#九网页版不用装-app课堂推荐)。

## 一、目录里有什么

| 路径 | 说明 |
|---|---|

| `settings.gradle.kts` / `build.gradle.kts` / `gradle.properties` | Gradle 工程配置 |

## 二、先确认端口（最重要的一步）

厂商固件不同批次监听的端口不一样，新 App 里我是这么猜的：`192.168.4.1:2001`、`192.168.1.1:2001`，另外把 8080/9000/5000/80 也作为候选一起探测。

**在电脑上先跑一次扫描**，把电脑（或手机）连到模块热点后：

```bash
python tools/rgb_tool.py --scan
```

输出里出现 `OPEN` 的那个 `IP:端口` 就是模块的真实入口。扫不到的话，先看本机网关：

```bash
ipconfig          # Windows，看"默认网关"
```

拿这个网关地址当 host 再扫：`python tools/rgb_tool.py --scan 192.168.x.1`

扫到以后直接发一条命令验证（**这是整条链路的关键验证**）：

```bash
python tools/rgb_tool.py --send 192.168.4.1 2001 "$RGB-R255-G000-B000^"
```

灯变红 = 链路全通。也可以双击脚本打开图形界面调色。

> PowerShell 里 `$RGB` 会被当成变量，用单引号或改成 `--send 192.168.4.1 2001 '$RGB-R255-G000-B000^'`。

## 三、怎么拿到 APK

当前应用版本是 **1.1**（versionCode 2）。发布出去的安装包是 **debug 调试包**（调试证书签名，不是应用商店用的正式签名）。安装时需要允许「安装未知来源应用」。

仓库地址：[https://github.com/FClSC/rgb-lan-tool](https://github.com/FClSC/rgb-lan-tool)。

### 方式 1：GitHub Release（推荐）

打开 [Releases](https://github.com/FClSC/rgb-lan-tool/releases)，下载对应版本的 APK。1.1 的文件名是 `rgb-lan-tool-1.1-debug.apk`（名字里的 `debug` 表示调试包）。

推送 `v*` 标签（例如 `v1.1`）时，GitHub Actions 会自动编译并创建 Release，把这个 APK 挂上去。

### 方式 2：Actions 产物（没有 Release 时再用）

1. 打开仓库的 **Actions**，进入最近一次成功的 `build-apk`；
2. 页面底部 **Artifacts** 下载 `rgb-lan-tool-debug-apk`；
3. 解压得到 APK，发到手机上安装。

也可以手动触发：Actions → build-apk → Run workflow。每次 push 也会构建一份 debug APK。

### 方式 3：本机编译

需要 JDK 17 和 Android SDK。在仓库根目录：

```bash
./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

用 Android Studio 也可以：`File → Open` 打开本文件夹，等 Gradle 同步完，`Build → Build Bundle(s) / APK(s) → Build APK(s)`。

### 方式 4：不装 App，用现成的 TCP 工具

手机上任意「网络调试助手」选 TCP 客户端，连 `扫到的IP:端口`，发 `$RGB-R255-G000-B000^`。
功能最少，但足够完成实验。

## 四、App 怎么用

1. 手机连上模块热点（名字通常是 `MakeRobot` + 设备ID）；
2. 打开 App，点 **自动查找** —— 它会把上面的候选地址挨个试，找到就自动连上；
3. 拖 R/G/B 滑块，或点「红/绿/蓝/白/灭」；
4. 日志里出现 `→ $RGB-R255-G125-B000^` 就说明字节发出去了。

### 自定义按钮（其它实验课用这个）

界面上有一块「自定义按钮」，每个按钮 = 一个名字 + 一段要发送的文本：

- 点 **＋ 新增按钮** → 填名字（可留空，留空就用内容当名字）+ 填写要发送的字符串 → 保存；
  - 新增时内容框会默认填入下面「任意命令」框里的内容，改一改就能加，
  - 所以标准用法是：先在「任意命令」里试通一条，再一键存成按钮；
- **长按**任意按钮（或编辑弹窗里的「删除」）可以改名字/内容，或删掉；
- 全部存在手机本地（SharedPreferences），关掉 App 也不会丢；
- 首次安装会预置 8 个常用按钮：

| 按钮 | 发送内容 |
|---|---|
| 实验1 LED | `$LED-S11-S21-S30-L1100-L2050-L3000^` |
| 实验2 鸣笛 | `$BEEP-1^` |
| 实验3 温湿度 | `$TH-1^` |
| 实验4 闹钟 | `$CLK-0-2017-11-10-15-23-20-5^` |
| 实验5 超声波 | `$UTL-XXX-123-X^` |
| 继电器 开 / 关 | `$RELAY-1^` / `$RELAY-0^` |
| 舵机 90° | `$SERVO-90^` |

完整 20 课协议写在厂商表格《AR套件物联网微信控制协议V180628》里（这份 xlsx **没有**放进本仓库），照抄内容即可。

## 五、协议约定（必须遵守，否则单片机不理你）

```
手机 → 设备：  $RGB-R255-G125-B000^
设备 → 手机：  $RGB-0#   （0成功 1失败 2不匹配）
```

- **包头 `$`，包尾 `^`**（设备上报用的是 `#`，别混）
- 三个分量**必须三位数字**：`0` 写 `000`，`12` 写 `012`
- 串口固定 **9600 8N1**
- 模块是**透传桥**：不解析、不校验、不拼帧，所以你发什么它转什么

## 七、常见问题

| 现象 | 原因 |
|---|---|
| 自动查找全不通 | 手机没连模块热点；模块开关不在**局域模式**（拨好后断电重上）；端口不在候选列表里 → 用 `rgb_tool.py --scan` 找 |
| 连上了但灯不动 | 模块 TX/RX 与 Arduino 接反、没共地；Arduino 程序里 `Serial.begin(9600)`；命令格式（三位数字 + `^`） |
| 灯亮了但颜色反 | RGB 模块是共阳的，把值取反（255 减） |
| 烧程序失败 | 模块的 TX/RX 接在 0/1 上，**上传时必须拔掉这两根线** |
| 手机连热点后自动切回移动数据 | 关掉"智能网络切换/WLAN+"，否则 TCP 会被掐断 |

## 九、网页版（不用装 App，课堂推荐）

### 为什么要桥接

**浏览器不允许打开原始 TCP 连接**（只有 WebSocket / HTTP 可用），而模块提供的是裸 TCP 透传。所以网页不能直接连模块，中间需要一个桥接：

```
手机浏览器 --HTTP--> bridge.py --TCP--> WiFi模块 --串口--> Arduino
```

`bridge.py` 已经把网页也一起托管了，你只需要跑一个文件。

### 怎么跑

```bash
python web/bridge.py
```

启动后会打印地址，例如：

```
手机/电脑打开：  http://192.168.4.2:8770
```

**这台电脑要先连上模块热点**，网页上点【自动查找】即可（约 8 秒，全部不通会明确告诉你）。

### 课堂用法（一台电脑带全班）

1. 教师电脑连上模块热点 `MakeRobot…`；
2. 教师电脑运行 `python web/bridge.py`，记下打印的 `http://电脑IP:8770`；
3. 学生手机也连同一个模块热点，浏览器打开这个地址——**不用装 App、不用扫码**；
4. 谁拖滑块，模块就收到谁的命令。

顺带解决了一个坑：这类模块通常只允许 **1 个 TCP 客户端**，多台手机同时连会互相踢掉；走桥接后只有桥接程序连模块，几十台手机都只是访问网页。

### 网页版功能

- 自动查找 / 手动填 IP 端口 / 连接状态
- R、G、B 三滑块 + 红绿蓝白灭预设，拖动即发送（130ms 防抖）
- **自定义按钮**：名称 + 发送内容都能改，存在浏览器 localStorage 里，关机重开还在；点【编辑】后点按钮即可改/删
- 任意命令框
- 日志区：`→` 是本机发出去的，`←` 是**模块回传的字节**（十六进制 + 文本），
  单片机回了 `$RGB-0#` 你能直接看到，排错非常有用
- 状态栏显示本机 IP；如果本机和模块不在同一网段（连错 WiFi），页面会直接警告

### 局限

- 必须有一台电脑在场并运行桥接（手机自己跑不了 Python）；
- 电脑和手机都得连在模块热点上，否则到不了模块；
- 想"完全不要电脑"，还是得用安卓 App 那条路。
